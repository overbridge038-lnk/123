# 誤品照合アプリ

製造現場で、**現品の写真**と**マスター写真**を比べて、品番の取り違え（誤品）を **OK / NG** で判定するアプリです。
Androidタブレットの Chrome で動き、ホーム画面に追加すればアプリのように使えます。

- 判定の仕組み：写真を AI（MobileNetV2）で数値の並び（特徴量）に変え、2枚の「似ている度合い（類似度）」を計算します。顔認証と同じ考え方です。
- **マスター（品番・マスター写真・しきい値）は Firebase（無料の Spark プラン）で全タブレットと共有**します。登録・変更・削除ができるのは**管理者だけ**で、それ以外の人は照合だけです。
- 照合の計算（特徴量・類似度）は**各タブレットの中**で行います。マスターは各タブレットにコピーして持つので、一度同期すれば**オフライン（電波なし）でも照合できます**。
- 現品の写真と履歴は**クラウドに送らず**、各タブレットの中（IndexedDB）にだけ保存します。
- AIモデルと Firebase の部品は自前ファイルとして同梱しており、外部のCDNに依存しません。

**はじめに：クラウド共有の設定は [CLOUD_SETUP.md](CLOUD_SETUP.md) の手順（Firebase の準備と `firebase-config.js` への貼り付け）を先に済ませてください。**

## 1. 公開する手順（GitHub Pages・初心者向け）

アプリは「ただのファイルの集まり」なので、GitHub Pages という無料サービスに置くだけで使えるようになります。

1. GitHub のこのリポジトリを開きます。
2. 上のタブ **Settings**（設定）をタップします。
3. 左のメニューから **Pages** を選びます。
4. **Build and deployment** の **Source** を **Deploy from a branch** にします。
5. **Branch** を `main`（このアプリのファイルが入っているブランチ）、フォルダを `/ (root)` にして **Save** を押します。
6. 1〜2分待ってページを更新すると、上の方に `Your site is live at https://（あなたの名前）.github.io/（リポジトリ名）/` と表示されます。これがアプリのアドレスです。

> ブランチが `main` でない場合は、このアプリのファイルを `main` ブランチに取り込んでから（プルリクエストをマージ）、上の手順をしてください。

## 2. タブレットで使い始める手順

1. タブレットの **Chrome** で、上のアドレスを開きます。**最初の1回は必ずWi-Fiなどネットに繋いだ状態**で開いてください（AIモデル約14MBを端末に保存するため）。
2. 画面上部の黄色い帯「AIモデルを読み込み中…」が消えたら準備完了です。
3. 初めてカメラを使うとき、「カメラの許可」が出たら **許可** を押します。
4. Chrome 右上の **︙（メニュー）→「ホーム画面に追加」**（または「アプリをインストール」）を押します。ホーム画面にアイコンができます。
5. 以後はそのアイコンから起動します。電波がなくても使えます。
   - 「設定」タブの「アプリ情報」に **オフライン動作：準備OK** と出ていれば大丈夫です。

## 3. 使い方

### ⓪ ログインと同期
- 初回はネットに繋いでログインします（アカウントは管理者が Firebase で作成します）。以後はログインしたままで、オフラインでも起動できます。
- 照合画面の上部に **「☁ 同期済み」「オフライン：端末内のマスターで照合中」** と表示されます。マスターは、アプリを開いたとき・ネットに繋がったとき・10分ごと・「設定」の「今すぐ同期」で更新されます。
- **管理者でない人**は、「マスター」タブで品番と写真を見られますが、登録・変更・削除はできません。

### ① マスター写真を登録する（管理者のみ・最初に1回）
1. 下の **「登録」** タブ → **「＋ 品番を追加」** で品番（と品名）を入力します。
2. **「カメラで撮影して追加」** で、正しい品物を撮影します。四角の**真ん中**に品物が入るようにしてください。
3. 写真は自動で縮小・圧縮（640px・400KB以下）されて、クラウドに保存されます。1つの品番に20枚まで登録できます。置き方・明るさ・背景は、**実際に照合するときと同じ**にするのがコツです。**角度や向きを少し変えて2〜3枚**登録すると安定します。
4. 写真ファイルがある場合は **「写真ファイルから追加」** も使えます。

### ② 現品を照合する（毎回）
1. **「照合」** タブで上の品番ボタンを押し、品番を選びます。マスター写真が左に表示されます。
2. 右のカメラの四角の中に現品を入れ、**「撮影して照合」** を押します。
3. 大きく **OK（緑）** または **NG（赤）** と、類似度が表示されます。ブザーとバイブでも知らせます。
4. **「次の照合へ」** で次の品物へ。結果は自動で履歴に保存されます。

### ③ 履歴とCSV
- **「履歴」** タブで一覧を確認できます（品番・OK/NGで絞り込み可）。写真をタップすると、そのときの現品写真を見られます。
- **「CSVで書き出し」** で、表示中の履歴を CSV ファイルとして保存します（Excel でそのまま開けます）。

## 4. しきい値の調整（とても大切）

OK / NG は「類似度が**しきい値以上なら OK**、未満なら NG」で決まります。標準は **70%** です。
このAIは一般的な画像用で、あなたの現場の部品専用に学習したものではないため、**実際の品物で調整が必要**です。

1. 正しい品物を何度か撮影し、類似度を見ます（例：85〜95%）。
2. わざと誤品（似た別品番）を撮影し、類似度を見ます（例：50〜70%）。
3. 両者の**真ん中あたり**を、管理者が「登録」タブ → その品番 → **しきい値** に設定します（全タブレットに共有されます）。品番ごとに決めていない場合は、「設定」の標準しきい値（管理者だけ変更可）が使われます。
4. 誤品なのに OK になる場合はしきい値を**上げ**、正しい品物なのに NG になる場合は**下げ**ます。

**精度を上げるコツ**：同じ場所・同じ明るさで撮る／背景を無地にする／マスターを複数枚登録する／カメラを品物に近づけて大きく写す。
色や小さな刻印だけが違う誤品は、見分けにくいことがあります。導入前に、実際の誤品パターンで必ず試してください。

## 5. ファイル構成

| ファイル | 役割 |
| --- | --- |
| `index.html` / `style.css` / `app.js` | アプリ本体（画面・見た目・動き） |
| `cloud.js` | クラウド（Firebase）とのやりとり |
| `firebase-config.js` | **Firebase の接続設定（あなたが貼り付けるファイル）** |
| `firestore.rules` | データを守るセキュリティルール（Firebase コンソールに貼り付ける） |
| `CLOUD_SETUP.md` | クラウド共有の設定手順（初心者向け） |
| `sw.js` | オフラインで動かすための仕組み（Service Worker） |
| `manifest.json`, `icons/` | ホーム画面に追加するための設定とアイコン |
| `vendor/tf.min.js` | AIを動かすライブラリ（TensorFlow.js 4.22.0・Apache-2.0） |
| `vendor/firebase/` | Firebase のライブラリ（12.19.0・Apache-2.0）。外部CDNを使わず自前で配信 |
| `model/` | AIモデル本体（MobileNetV2・Apache-2.0。Google が TensorFlow.js 用に公開しているもの） |

## 6. アプリを更新したとき

ファイルを書き換えたら、`sw.js` の `const CACHE = 'gohin-v3';` の番号を `v4`、`v5` …と上げてください。更新後はアプリを一度閉じて開き直します。
（`app.js` などのアプリ本体は、ネットに繋がっていれば自動で最新が使われます。AIモデルや Firebase の部品など大きなファイルだけが、番号を上げたときに入れ替わります。）

## 7. 注意

- 履歴と現品の写真はタブレットの中だけにあります。**Chromeの「サイトデータを消去」やアプリの削除をすると、履歴は消えます。**履歴は定期的にCSVで書き出してください。（マスターはクラウドにあるので、ログインし直せば再び同期されます。ログインにはネット接続が必要です。）
- 管理者が品番や写真を削除すると、全タブレットから消えます。元に戻せないので、元の写真は別に保管してください。
- 許可リストから外された人は、次にネットに繋いだとき、端末内のマスターのコピーが消えて使えなくなります。
- カメラは https で配信されたページでのみ使えます（GitHub Pages は https です）。
